# On Quantum Mechanics

## Introduction

This is a brief sketch on building quantum mechanics from basic experimental facts.

## Motivation

I used to write a brief note about stochastic process. Still unfinished, I got stuck. So, I turn my attention to a similar topic, the quantum mechanics, exploring how to apply the techniques developed in stochastic process to quantum mechanics.

In short, *just for fun*.

## File Structure

- main.tm: The TeXmacs file of the note.
- public
  - main.pdf: The PDF output of the note.
- scripts: Includes the codes in the note.
  - uncert.wxmx: The maxima (using GUI WxMaxima) codes in the section about uncertainty principle.

## How to Contribute

- Editing using TeXmacs (together with TeXlive).
- Run scripts in WxMaxima (the GUI version of Maxima).
